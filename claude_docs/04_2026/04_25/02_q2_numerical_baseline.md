# 02 — Q2: Numerical-Prompt Baseline

## Question being addressed
Reviewer Q: "You could compare against the image generated by simply combining the prompts (ignoring the bids) or by explicitly saying in the prompt that you want an image that is 20% aligned with X and 80% aligned with Y."

## Hypothesis
Verbalizing bid-as-percentage in the prompt does **not** produce bid-monotone allocation, while our auction does. The auction should beat this baseline on both monotonicity and welfare.

### Prompt template
```python
def build_numerical_prompt(base_prompt, agent_prompts, bids):
    clauses = [f"{int(round(bid * 100))}% aligned with {prompt}"
               for prompt, bid in zip(agent_prompts, bids)
               if bid > 0.0 and prompt]
    if not clauses:
        return base_prompt  # (0, 0) → just base
    return f"{base_prompt} that is " + " and ".join(clauses)
```

Examples:
- `(0.0, 0.0)` → `"{base}"`
- `(1.0, 0.0)` → `"{base} that is 100% aligned with {a1}"`
- `(0.7, 0.3)` → `"{base} that is 70% aligned with {a1} and 30% aligned with {a2}"`
